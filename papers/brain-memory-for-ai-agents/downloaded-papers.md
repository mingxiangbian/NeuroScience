## Scope

这一批文件服务 `记忆与智能体` 的第一轮学习：先搭起人脑记忆机制与 AI agent memory 的共同问题框架，而不是追求论文数量。

原则：

- 优先收录综述、经典理论论文和已被广泛引用的 agent memory 架构论文。
- 原文文件保存在 `pdfs/` 或 `html/`。
- 中文学习稿保存在 `notes-cn/reading-packet-cn.md`。
- PMC / Nature 等页面如果非 Open Access PDF 或自动下载被校验拦截，则保存公开 HTML 页面，不伪装成 PDF。
