# 投资学习

这是公开的长期投资学习阅读器，用于快速理解概念依赖、恢复进度、搜索术语和整理可公开的知识笔记。页面默认使用夜间黑金研究界面，也提供独立记忆的日间墨白主题。

## 使用方式

1. 从「学习总览」查看概念依赖图：聚焦节点可同时查看直接前置、直接下游及其在投资决策中的作用。
2. 点击图谱节点、决策说明或学习账表，直接进入对应模块；模块切换会从正文顶部开始。
3. 使用全文搜索查找术语、公式和案例；桌面表格采用终端式密度，移动端在表格内部横向滚动。
4. Finance 的模块正文、列表、表格和知识文章均可批注。选中文字即可添加本地高亮或笔记；本地批注只保存在当前浏览器。需要长期保留的理解应写回对应 Markdown 模块。

主题选择、批注栏开合状态与 Foundations 阅读器分别记忆，不会互相覆盖。

## 内容与构建

- 内容源：`roadmap/modules/*.md`
- 构建命令：`node scripts/build-roadmap-data.mjs`
- 页面数据：`roadmap/roadmap-data.json`

## 隐私边界

这是公开站点，不保存持仓、交易、账户或个人财务信息，也不记录真实投资决策。页面内容只用于学习，不构成个性化投资建议。
