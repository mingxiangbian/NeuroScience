新建话题分析

冻结模型，对一份可追溯的内容快照作描述性分析。

失败尝试也计入预算；精确输入缓存命中不占次数。缓存只在本任务内复用。

内容文件

只需文本字段。可选 id、url、created_at；时间必须带时区。其他字段（包括标签）不会用于评估。原文不作归一化，缺日期的内容不进入趋势图。

Python Discussions · Python Help

固定来源 discuss.python.org / Python Help。按主题创建时间降序取分类前缀，再按帖子序号读取。此入口不运行站内搜索，也不承诺固定日期窗口。

实际时间范围、停止原因和来源信息随快照保存。只描述本次采集前缀，不代表全部 Python 社区。

Stack Overflow 采样窗口

先按创建时间升序取窗口内的问题，再取这些问题相关、同窗口内的回答与评论。不是全站事件流；上限、API 配额与停止原因随快照保留。

结果仅描述这份采样内容中的模型预测，不代表论坛整体情绪或模型在新数据上的准确率。CancerEmo 等外部金标泛化本阶段不执行。

导出 JSON逐条 CSV

预测并非金标。多标签比例可相加超过 100%；neutral 仅表示六个标签均未触发。未完成或失败的内容不计入预测分母。

六标签趋势 · UTC

每个时间桶独立计算所选口径。无日期的内容不进入趋势；没有内容的日期不补零。

对象类型与路由分层

沿用当前权重与比例开关，每层独立计算分母并归组。路由分组来自模型决策，不是随机对照；unknown 表示缺少该决策回执。跨层的唯一组数不能相加当作全局唯一组数。

路由与实际计算

始终按真实内容与 forward 计数，不随 Unique-text 视图变化。成对分歧只覆盖同时获得两模型决策的子集。

预测与输入诊断

Cardinality 是每条内容触发的标签数。熵与阈值距描述模型输出，不能解释为外域准确率或正确概率。

Token 长度与截断

按有长度记录的成功回执统计，含精确输入缓存命中；不是额外调用次数。M3 仅覆盖实际获得 M3 输出的子集；缺失记录显示为不可用。
