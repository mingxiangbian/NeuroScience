## 为什么做

没有长期记忆的 Agent 很难保持跨会话的项目上下文、偏好更新与连续协作。但“长期记忆”不能只被缩减成向量检索，也不能因为使用了神经科学词汇，就默认模型和大脑共享机制。

这个项目追问的是：人脑记忆研究能为 Agent memory 提供哪些可迁移的计算原则，哪些只是有用类比，哪些目前不能迁移。

## 做了什么

建立了一套结构化研究工作区，包括项目问题与边界、分阶段研究路线、机制到工程设计的映射，以及需要继续核查的假设。

当前映射覆盖编码特异性、海马索引、模式分离与模式补全、系统巩固、再巩固、遗忘和离线重放等机制。工程侧则拆成写入、检索、整合、纠错、遗忘与审计等生命周期环节。

## 关键选择

没有把“AI 像大脑”当作前提，而是依次区分神经科学机制、计算原则和 Agent 设计约束。每条映射同时标记证据强度、结论来源类型和迁移风险。

这也意味着，一个系统能检索旧文本，并不足以说明它拥有可用的长期记忆。可追溯来源、冲突更新、用户纠错与删除权同样属于设计本体。

## 结果与反思

第一版映射形成了五类设计约束和一组典型失败模式，包括错误个性化、虚假记忆、过度检索、记忆固化、隐私泄漏与摘要漂移。

当前成果是研究框架，不是生产级记忆系统。多项跨域迁移仍属于初步判断，需要继续补充文献和可执行评估；页面不会把这些判断写成已经成立的领域共识。
