# 札记

`札记` 是接入现有 GitHub Pages 的公开个人记录站。它区分两类内容：

- `博客`：问题、理解、修正与长期思考记录。
- `成果`：学习过程中真正做过的研究框架、阅读器、实验、工具或阶段性作品，不是奖项陈列。

页面使用 Markdown 作为唯一内容源，在提交前生成完整静态 HTML。LaTeX 只用于 Markdown 正文里的数学表达。

## 目录

```text
content/blog/*.md          博客源文件
content/works/*.md         成果源文件
assets/zaji.css            全站视觉与响应式样式
assets/zaji.js             阅读进度、公式和成果预览增强
assets/works/*.webp        真实成果页面预览
scripts/markdown.mjs       Markdown、安全清洗、代码与公式占位
scripts/build-site.mjs     静态页面生成与只读一致性检查
index.html                 生成：首页
blog/**/index.html         生成：博客索引与详情
works/**/index.html        生成：成果索引与详情
```

生成的 HTML 顶部带有 `Generated by` 注释，不应手工编辑。

## 内容契约

文件名就是 URL slug，使用小写英文与连字符。正文只从 `##` 开始，页面模板负责唯一的 `h1`。

博客必填字段：

```yaml
---
title: 标题
date: 2026-07-19
summary: 一句话摘要
tags: [标签一, 标签二]
related_works: [optional-work-slug]
---
```

成果还需要：

```yaml
status: 持续构建
type: 研究项目
cover: assets/works/example.webp
cover_alt: 对真实预览画面的准确说明
live_url: /NeuroScience/projects/example/
source_url: https://github.com/example/repository
related_posts: [optional-post-slug]
```

正文图片只接受站内 `assets/` 路径或 HTTPS 地址，并且必须提供 alt。代码块支持 Bash、JavaScript、JSON、Markdown、Python、Rust、TypeScript 和 YAML。

公式语法：

```markdown
行内公式：\(x + y\)

\[
E = mc^2
\]
```

## Agent 发布流程

1. 新建或更新 Markdown 与真实媒体。
2. 运行 `npm run build:zaji` 生成静态页。
3. 运行 `npm run test:zaji`，确认源文件、生成页、安全渲染和内部链接一致。
4. 运行相关全站测试，并只暂存本次涉及的明确文件。

首版不加入草稿状态、CMS、评论、搜索、RSS、后端或客户端内容请求。进入 `main` 的内容即为公开内容；未完成草稿留在未合并分支。
