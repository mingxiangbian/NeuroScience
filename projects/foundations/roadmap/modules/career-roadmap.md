## 目标

长期目标：实现贾维斯式的智能陪伴助手——有记忆、有情感表达、能办事的类人 AI。

核心理由是内在的：**我长期想研究并创造能理解人、记住人、与人持续互动并采取行动的智能系统**。这个理由在市场冷却、公司消失、岗位名称变化之后依然成立。（时代背景：Character.AI、星野/Talkie、猫箱、AI 陪伴硬件、各家大模型的 memory 功能——它们说明这条路当下有真实产业，但它们是背景，不是理由。）

没有人能独自造出完整的贾维斯，所以把它翻译成可执行的**个人目标函数**：

**当这样的系统被造出来时，我在造它的房间里，并且握着其中 1–2 个核心子系统。**

### 贾维斯的六个子系统

- ① **基座模型**：大厂造，不用造，但必须懂原理。
- ② **人格与情感**（post-training：SFT/DPO/RLHF）：**候选专长**，接我的训练经验，也是我当前最想探索的方向。
- ③ **终身记忆**（写入、整合、遗忘、反思）：**候选专长**，接我的 agent 经验，学界正热。研究工作区见「记忆与智能体」。
- ④ **实时多模态交互**（语音、视觉、全双工）：**候选专长**，接我的 EE/信号处理本行。
- ⑤ **Agent 执行**（工具、规划、沙箱）：已有经验（Cyrene 0.0），载体将换 Python 重新生长。
- ⑥ **系统层**（推理优化、延迟、成本、端侧）：需补课，是②③④跑起来的地基。

战略：②③④ 三选一到二做成专业级深度，其余保持"能设计、能对话"的工作性理解。路线图的每一步都必须回答：这一步怎么让我离那个房间更近。

### 北极星：贾维斯 0.x 血脉

北极星不是某个具体代码库，而是"贾维斯 0.x"这条系统血脉。现有 TS 版 Cyrene 归档为 **0.0**：它证明了我能搭出 agent 架构，但它是 vibe-coding 的产物（TS 并非我的语言），已到重写点，不再往里整合。从 U7 起用 Python 从零长出 **0.1**（最小陪伴循环），之后每个子系统的成果都往 0.x 上装。独立小项目允许先行，成熟后再并入。

## 核心知识

### 运行规则（结算制学习系统）

- **结算制**：唯一有效动作是"结算一个单元"。单元 = 2–4 个 session 内可完成、产出一个跑得起来的东西或一篇笔记。台账数字只涨不跌。
- **单线程**：任何时刻只有一个活动单元，其余冻结在队列。队列不是债，是弹药库。
- **无日历**：没有每日任务、没有打卡、没有周目标、没有 streak。空窗任意长，回来时系统原样等着，不记债。外部硬期限走日历，不进本系统。
- **断点续传**：每个 session 结束在台账留三行断点（做到哪 / 下一步第一个动作），或直接告诉 Claude。重启成本目标 < 5 分钟。
- **卡住协议（状态触发，无计时器）**：信号 = 同一报错第三次原地转、漫无目的开标签页、烦躁想关电脑。动作 = 三行墙记录（在做什么/卡在哪/试过什么）→ 丢给 Claude 或写进台账 → 合法离场。撞墙记录可升级为失败分析笔记，照常结算。心流中的硬磕不受任何限制。
- **玩耍券**：每结算 2 个主线单元得 1 张，不过期可累积。玩耍单元 = 拿最新模型/工具随便造，无需产物即可结算——这是对冲新鲜感衰减、跟上"快层"的全部机制。
- **军火库**：CSAPP、C++、论文不作为任务存在，只在活动单元撞到对应的墙时取用，取用后把学到的写进当次产物。为打基础而打基础，禁止。

### 结算判据（按单元类型）

结算时由 Claude 按类型问两三个问题，产物 + 回答即结算——判据的执行摩擦落在 Claude 身上，不落在我身上。跑通不等于理解，写完不等于掌握，判据就是防这个的。

- **实现单元**：可运行结果 + 最小测试 + 一句"为什么这样设计"。
- **实验单元**：假设 + 对照 + 结果 + 失败解释。
- **理论单元**：能脱离资料复述 + 连接到当前系统 + 一个仍未解决的问题。
- **整合单元**：两个以上子系统真实交互 + 记录接口与冲突。
- **探索单元**：可以没有成功产物，但必须说明它改变了什么判断。

### 深度阶梯（候选专长的定向仪）

统一五层：**理解 → 实现 → 验证 → 诊断 → 综合/创新**。只在结算和校准时用来回答"我现在站在哪一层"，不做逐格追踪、不配百分比。

- **② 人格**：懂 post-training 原理 → 跑通 SFT/DPO → 设计行为对比 eval → 解释为什么没变/变坏 → 提出自己的人格塑造方案。
- **③ 记忆**：写入与检索 → 冲突与遗忘 → 长期一致性 eval → 与人格和用户模型交互 → 自己的记忆机制假设。
- **④ 语音**：懂实时语音栈 → 搭出 pipeline → 延迟与打断实验 → 定位体验劣化的原因 → 节奏与情感的自主设计。

### 校准（事件触发，无日历）

触发条件（任一满足，由 Claude 主动发起）：结算满 3 个主线单元 / 一次候选专长试驾结束 / 某个实验推翻了原有理解 / 贾维斯 0.x 的设计发生明显变化 / 进入新的学习阶段。

每次只答四问，几行即可，记入台账"校准记录"：

1. 我对贾维斯的理解改变了什么？
2. 哪个子系统比之前更重要或更不重要？
3. 当前主线仍是信息增益最高的下一步吗？
4. 哪个原有假设应降级、删除或继续验证？

结算记录永久只涨；"当前理解"和置信度允许下降——台账和信念是两本账。

### 四阶段路线

- **阶段一（现在 → 2027.08，出国前）**：单元队列 U1–U7（验证能力 → 人格试驾 → 0.1 点火）+ 军火库按需。
- **阶段二（2027–2029，硕士）**：从②③④选定 1–2 个子系统做出第一个专业级作品。选课往 NLP/对话/语音/HCI 靠；第一个月就去敲对话/记忆/情感实验室的门；实习进有陪伴/角色/记忆产品的团队。
- **阶段三（2029–2032，职业早期）**：进入正在造贾维斯部件的团队，认准岗位名里的 memory、personalization、character/role-play、voice、agent platform。
- **阶段四（2032+，出口）**：在大平台内部主导陪伴/个性化方向，或带专长创业。

### 学习方法论

- **北极星血脉牵引**：每攻下一个子系统就往贾维斯 0.x 上装一块（今年装人格，之后装记忆、语音；验证纪律不是部件，是装每块部件的手艺）。
- **AI 当教练，不当代驾**：让 AI 讲解、出题、review 是涨能力；让 AI 代写是原地踏步。检验：不开 AI 能否手写 attention、讲清 KV cache 为何省显存。Cyrene 0.0 就是代驾的代价样本。
- **输出倒逼输入**：每学透一块写成笔记；写不清楚就是没懂。
- **验证纪律**：任何模型/系统先问"我怎么知道它真的在工作"。

### 行动 → 子系统 → 阶段映射

- U1–U3（修 mask + eval + 笔记）→ 全部（验证地基）→ 现在。
- U4–U7（SFT → DPO → 人格笔记 → 0.1 点火）→ ② 人格情感 + ⑤ → 出国前。

- 对话/记忆/情感实验室 + 相关实习 → ②③④定专长 → 硕士。

### 反迷茫检验

任何学习活动，必须至少完成以下一项，否则不做：**给贾维斯 0.x 增加一个部件 / 改善一种评估 / 解释一个机制 / 暴露一个错误假设 / 改变一个设计决策**。再加一问：它让我离"造贾维斯的房间"更近了吗？

一次只开一个单元，结算了再抬头看路。方向的校准交给"校准"机制，不靠焦虑。

## 任务

结算制：产物可指认且判据成立后，才由对话流程写入源码与台账；网页按钮只做本地登记，不产生正式结算。队列不是债——空窗任意长，回来接着上。

### 已结算单元（台账只涨不跌）

1. **U1 修掩码**（1–2 sessions，实验单元）：已结算（2026-08-07）。在同 seed、数据与超参数下只改变 `is_causal`：causal loss 每轮略高，最大差 `0.0809`、最终差 `0.0015`；简单递增规律让 causal 很快追上，两组都接近随机末位造成的 `0.6908` 理论下限。产物：epoch-average 对比曲线 + U1 结算笔记；限制：训练脚本未自动保存逐 step 原始 loss。**顿悟点：低 teacher-forced training loss 不能证明自回归生成正确，信息边界与评估条件必须和推理一致。**

### 活动单元（一次只有一个）

1. **U2 揭穿作弊**（1–2 sessions，实验单元）：两个指标对照——teacher-forced 的 held-out loss（作弊模型照样拿假低分：答案就在右边一格，没见过的数据也一样）vs 自回归生成质量（作弊立刻现形）。"假指标 vs 真指标"的反差就是本单元的顿悟点。产物：eval 脚本 + 对比数据。

### 近期队列（冻结，按序解冻）

1. **U3 第一篇笔记**（1 session，理论单元）：《我的 decoder 没有 mask》——U1+U2 的完整故事，含失败分析。
2. **U4 SFT 试驾**（2–4 sessions，实现单元）：Qwen 小尺寸 + LoRA SFT，改掉模型的一个具体行为。解冻前先定两件事：算力路径（Mac 走 MLX / 免费 Colab 走 QLoRA）与 SFT 数据来源（现成人设对话集或自造小集）。产物：before/after 对话样例 + 训练脚本。
3. **U5 DPO 试驾**（2–4 sessions，实验单元）：构造小偏好集，跑通 DPO。注意：小规模偏好集下行为差异可能很微弱——"看不出变化"本身也是合法结果，写清楚为什么即可结算。产物：前后行为对比。
4. **U6 人格笔记**（1 session，理论单元）：《模型的性格是怎么被塑造的》。
5. **U7 贾维斯 0.1 点火**（2–3 sessions，整合单元）：新建独立 Python 项目，把 U4/U5 的人格模型包进一个最小对话循环（CLI 即可）——新载体的第一块骨头，旧 TS Cyrene 就此归档为 0.0。产物：能连续对话的 0.1 + 接口与冲突记录。

### 玩耍券

每结算 2 个主线单元得 1 张，不过期可累积。玩耍单元 = 拿最新模型/工具随便造，无需产物即可结算。当前：0 张。

### 远期队列（故意不细化，到队头再定义）

记忆系统（可独立项目起步）· 实时语音 pipeline · vLLM / llama.cpp 源码笔记 · CSAPP 军火库笔记（被墙触发才产生）· 整合单元：人格×记忆（长期一致性 vs 人格漂移）、记忆×Agent（记忆改善行动而不被错误记忆劫持）、语音×人格（节奏停顿语气如何改变人格感）、全系统（失败后如何恢复用户信任与控制权）。
