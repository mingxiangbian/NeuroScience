## 目标

长期目标：实现贾维斯式的智能陪伴助手——有记忆、有情感表达、能办事的类人 AI。这不是幻想，是正在爆发的真实赛道（Character.AI、星野/Talkie、猫箱、AI 陪伴硬件、各家大模型的 memory 功能）。

没有人能独自造出完整的贾维斯，所以把它翻译成可执行的**个人目标函数**：

**当这样的系统被造出来时，我在造它的房间里，并且握着其中 1–2 个核心子系统。**

### 贾维斯的六个子系统

- ① **基座模型**：大厂造，不用造，但必须懂原理。
- ② **人格与情感**（post-training：SFT/DPO/RLHF）：**候选专长**，接我的训练经验。
- ③ **终身记忆**（写入、整合、遗忘、反思）：**候选专长**，接我的 agent 经验，学界正热。研究工作区见「记忆与智能体」。
- ④ **实时多模态交互**（语音、视觉、全双工）：**候选专长**，接我的 EE/信号处理本行。
- ⑤ **Agent 执行**（工具、规划、沙箱）：已有基础（Cyrene），持续迭代。
- ⑥ **系统层**（推理优化、延迟、成本、端侧）：需补课，是②③④跑起来的地基。

战略：②③④ 三选一到二做成专业级深度，其余保持"能设计、能对话"的工作性理解。路线图的每一步都必须回答：这一步怎么让我离那个房间更近。

完整文档：[ai-professional-roadmap.md](ai-professional-roadmap.md)（战略层）；同目录 `llm-agent-engineer-roadmap.md` 是战术层（面试能力包）。

## 核心知识

### 运行规则（结算制学习系统）

- **结算制**：唯一有效动作是"结算一个单元"。单元 = 2–4 个 session 内可完成、产出一个跑得起来的东西或一篇笔记。台账数字只涨不跌。
- **单线程**：任何时刻只有一个活动单元，其余冻结在队列。队列不是债，是弹药库。
- **无日历**：没有每日任务、没有打卡、没有周目标、没有 streak。空窗任意长，回来时系统原样等着，不记债。外部硬期限（雅思、申请）走日历，不进本系统。
- **断点续传**：每个 session 结束在台账留三行断点（做到哪 / 下一步第一个动作），或直接告诉 Claude。重启成本目标 < 5 分钟。
- **卡住协议（状态触发，无计时器）**：信号 = 同一报错第三次原地转、漫无目的开标签页、烦躁想关电脑。动作 = 三行墙记录（在做什么/卡在哪/试过什么）→ 丢给 Claude 或写进台账 → 合法离场。撞墙记录可升级为失败分析笔记，照常结算。心流中的硬磕不受任何限制。
- **玩耍券**：每结算 2 个主线单元得 1 张，不过期可累积。玩耍单元 = 拿最新模型/工具随便造，无需产物即可结算——这是对冲新鲜感衰减、跟上"快层"的全部机制。
- **军火库**：CSAPP、C++、论文不作为任务存在，只在活动单元撞到对应的墙时取用，取用后把学到的写进当次产物。为打基础而打基础，禁止。

- **阶段三（2029–2032，职业早期）**：进入正在造贾维斯部件的团队，认准岗位名里的 memory、personalization、character/role-play、voice、agent platform。
- **阶段四（2032+，出口）**：在大平台内部主导陪伴/个性化方向，或带专长创业。

### 学习方法论

- **北极星项目牵引**：Cyrene 不是作品集，是贾维斯 0.x——每攻下一个子系统就往里装一块。
- **AI 当教练，不当代驾**：让 AI 讲解、出题、review 是涨能力；让 AI 代写是原地踏步。检验：不开 AI 能否手写 attention、讲清 KV cache 为何省显存。
- **输出倒逼输入**：每学透一块写成笔记；写不清楚就是没懂。
- **验证纪律**：任何模型/系统先问"我怎么知道它真的在工作"。

## 任务

结算制：勾选 = 单元已结算（产物存在且可指认）。队列不是债——空窗任意长，回来接着上。

### 活动单元（一次只有一个）

1. **U1 修掩码**（1–2 session）：`is_causal=True` 修复 + 重训，产出修复前后 loss 曲线对比图 + 三行结论，进 repo。

### 近期队列（冻结，按序解冻）

1. **U2 揭穿作弊**（1–2 session）：held-out eval + 自回归生成检查，量化证明旧模型在"抄右边"。产物：eval 脚本 + 对比数据。
2. **U3 第一篇笔记**（1 session）：《我的 decoder 没有 mask》——U1+U2 的完整故事，含失败分析。
3. **U4 SFT 试驾**（2–4 session）：Qwen 小尺寸 + LoRA SFT，改掉模型的一个具体行为。产物：before/after 对话样例 + 训练脚本。
4. **U5 DPO 试驾**（2–4 session）：构造小偏好集，跑通 DPO。产物：前后行为对比。
5. **U6 人格笔记**（1 session）：《模型的性格是怎么被塑造的》。

### 玩耍券

每结算 2 个主线单元得 1 张，不过期可累积。玩耍单元 = 拿最新模型/工具随便造，无需产物即可结算。当前：0 张。
