## 0. 目标函数

**长期目标**：实现贾维斯式的智能陪伴助手——有记忆、有情感表达、能办事的类人 AI。

这个目标不是幻想，是正在爆发的真实赛道（Character.AI、星野/Talkie、猫箱、AI 陪伴硬件、各家大模型的 memory 功能）。但没有任何一个人能独自造出完整的贾维斯。所以把它翻译成**可执行的个人目标函数**：

> **当这样的系统被造出来时，我在造它的房间里，并且握着其中 1–2 个核心子系统。**

路线图的每一步都必须回答：这一步怎么让我离那个房间更近。

## 1. 终局拆解：贾维斯的六个子系统

| # | 子系统 | 内容 | 与我的关系 |
|---|--------|------|------------|
| ① | 基座模型 | 预训练大模型 | 大厂造，不用造，但必须懂原理 |
| ② | 人格与情感 | post-training：SFT / DPO / RLHF 塑造性格与共情 | **候选专长**——接我的训练经验 |
| ③ | 终身记忆 | 写入策略、整合、遗忘、反思 | **候选专长**——接我的 agent 经验，学界正热 |
| ④ | 实时多模态交互 | 语音、视觉、全双工对话 | **候选专长**——接我的 EE/信号处理本行 |
| ⑤ | Agent 执行 | 工具调用、规划、沙箱 | 已有基础（Cyrene），持续迭代 |
| ⑥ | 系统层 | 推理优化、延迟、成本、端侧 | 需补课，是②③④跑起来的地基 |

**战略**：②③④ 三选一到二做成世界级深度，其余保持"能设计、能对话"的工作性理解。

## 2. 现状画像（2026-07）

**已有的牌：**

- 从零实现 decoder-only transformer 并训练过小型模型（不只是读过论文）
- 自建 agent 框架 Cyrene（TS/Node/MCP，含 benchmark/release checks）
- 数学底子：线代、概率、统计建模（NIPT 数模省三、SVD 图像压缩）
- EE 本行：信号处理、嵌入式（机器人车）、数电计组基础
- 广度：GPT/BERT/MAE/GAN 论文、agent 生态、NeRF

**缺的三层（按重要性排）：**

1. **验证能力**。证据：toy transformer 仓库里 `scaled_dot_product_attention` 传了 `is_causal=False` 且无 mask——decoder 实际没有因果掩码，训练时每个位置都能看到答案，玩具数据太规则把 bug 藏住了。组装能力 ≠ 验证能力；没有 eval 就不知道模型是学会了还是在作弊。这是六个子系统共同的地基。
2. **CS 系统基本功**。CSAPP 级别的系统理解、一门系统语言（C++ 优先，因为 llama.cpp/vLLM 内核层都是它；Rust 可替代；Java 跳过；TS 维持够用即可）。
3. **深度**。五个"跑通了"的项目，还没有一个四个"有"俱全（有评估、有数据、有失败分析、有文档）的项目。

## 3. 四阶段路线

### 阶段一：现在 → 2027.08（出国前）

任务只有两件，其余都是干扰：

1. **把组装能力升级成验证能力**：修 causal mask bug → 对比修复前后 loss 曲线 → 建一个能揭穿"作弊模型"的 eval。这一套走完就拿到了造任何子系统的核心纪律。
2. **子系统②第一次试驾**：在 toy transformer 或 1B 级开源模型上走完 SFT → DPO 链路，亲手把一个模型的"性格"改掉——这是第一次直接触碰"AI 怎么会有人格"。

这两件事已切成产物单元 U1–U6，按[台账](ledger.md)结算制执行（见下文"运行系统"）。CSAPP/C++ 不是并行任务——转入军火库模式。雅思 6.5+ 是外部硬期限，走日历，不进结算系统（见[语言](../language/ielts-academic/)）。

### 阶段二：2027–2029（硕士）

任务：**从②③④里选定 1–2 个子系统，做出第一个专业级作品**（实验室论文或工业级实习项目）。

- 选课往 NLP/对话系统、语音处理、HCI 靠
- 落地第一个月就去敲做对话/记忆/情感计算的实验室的门（HKUST CAiRE、NUS WING、NTU 语音组一类）
- 实习进有陪伴/角色/记忆产品的团队（MiniMax、字节陪伴产品线、Character.AI 等）
- 硕士两年 = 把三个候选子系统试一遍、砍掉一个半

### 阶段三：2029–2032（职业早期）

任务：**进入正在造贾维斯部件的团队**——认准岗位名里的 memory、personalization、character/role-play、voice、agent platform。把学校里的深度换成工业规模经验：千万用户的记忆系统和笔记本上的记忆系统是两个学科。资源（算力、数据、用户）只在这些房间里有。

### 阶段四：2032+（出口）

在大平台内部主导陪伴/个性化方向，或带着子系统专长、规模化经验和行业人脉创业。到这一步，贾维斯从"我的梦想"变成"我的职务"。

## 4. 学习方法论

- **北极星项目牵引**：Cyrene 不是作品集，是贾维斯 0.x。每攻下一个子系统就往里装一块（今年装验证和人格，明年装记忆，硕士装语音）。十年持续迭代同一个系统，本身就是独一无二的履历。
- **项目牵引、按需补课**：不"先学完再做"，也不"只做不学"。撞墙 → 系统补掉那一块 → 继续。
- **AI 当教练，不当代驾**：让 AI 讲解、出题、review 我的代码是涨能力；让 AI 代写、我负责运行是原地踏步。检验点：不开 AI 能不能手写 attention？能不能给别人讲清 KV cache 为什么省显存？
- **输出倒逼输入**：每学透一块写成技术博客。写不清楚就是没懂；博客和 GitHub 是 AI 给不了别人的信号资产。
- **验证纪律**：任何模型/系统，先问"我怎么知道它真的在工作"。含金量 = 决策密度，不是选题大小。

## 5. 运行系统：抗中断的结算制

> 2026-07-17 与 Claude 讨论历史失败模式（中途而弃、学了没掌握、无成果焦虑、基础打转）后定稿。
> 设计前提：每周可支配时间很不稳定；奖励来源是"跑起来的瞬间、顿悟、进度可视"；计时器和日历承诺已被实践证伪。

1. **结算制**：唯一有效动作是"结算一个单元"。单元 = 2–4 个 session 内可完成、产出一个跑得起来的东西或一篇笔记。台账数字只涨不跌，账本在 [ledger.md](ledger.md)。
2. **单线程**：任何时刻只有一个活动单元，其余冻结在队列。队列不是债，是弹药库。
3. **无日历**：没有每日任务、打卡、周目标、streak。空窗任意长，回来时系统原样等着，不记债。外部硬期限（雅思、申请）走日历，与本系统隔离。
4. **断点续传**：每个 session 结束在台账留三行断点（做到哪 / 下一步第一个动作 / 有没有墙），或直接告诉 Claude。重启成本目标 < 5 分钟——时间不稳定的人真正的敌人是重新上下文成本，不是总时长。
5. **卡住协议（状态触发，无计时器）**：信号 = 同一报错第三次原地转、漫无目的开标签页、烦躁想关电脑。动作 = 三行墙记录 → 丢给 Claude 或写进台账 → 合法离场。撞墙记录可升级为失败分析笔记，照常结算——当撞墙也能赢，墙就杀不死计划。心流中的硬磕不受任何限制。
6. **玩耍券**：每结算 2 个主线单元得 1 张，不过期可累积。玩耍单元 = 拿最新模型/工具随便造，无需产物即可结算。这是对冲新鲜感衰减、跟上 AI"快层"的全部机制——快层不需要学，只需要用。
7. **军火库**：CSAPP、C++、论文不作为任务存在，只在活动单元撞到对应的墙时取用，取用后把学到的写进当次产物。为打基础而打基础，禁止——没有应用压力的基础学习既无聊又不粘。

## 7. 反迷茫检验

迷茫大多来自"什么都想抓"。两条检验，任何学习活动过不了就不做：

1. 它给 Cyrene（贾维斯 0.x）装上了什么部件？
2. 它让我离"造贾维斯的房间"近了一步吗？

方向感是做出来的，不是想出来的。一次只开一个单元，结算了再抬头看路。
