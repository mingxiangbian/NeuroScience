# 09 Evaluation Ledger Template

这是可提交的空白模板，不存真实面试题、transcript 或个人评分。实际训练记录写入同目录、已被 `.gitignore` 排除的 `09_eval_ledger.local.md`；后续润色不能覆盖原始 artifact。

## 使用规则

1. 每次 blind/coached 练习都记一行；`mode` 只能是 `blind` 或 `coached`。
2. `raw_answer_or_artifact` 填 transcript、代码、设计图或录音路径/链接，不贴润色后的答案。
3. `hints` 记录实质提示次数；大于 0 时 readiness level 最高为 1。
4. readiness level 与 failure tag 使用 06 的定义。
5. 未达到 level 2 的项目安排 D+2 和 D+7 变式；通过后写复测结果，不删除原记录。
