# IBM Plex Mono

The Foundations reader vendors two Latin subsets from
`@fontsource/ibm-plex-mono@5.2.7`:

- `IBMPlexMono-Regular.woff2` from `ibm-plex-mono-latin-400-normal.woff2`
- `IBMPlexMono-Medium.woff2` from `ibm-plex-mono-latin-500-normal.woff2`

The files are distributed under the SIL Open Font License included in
`LICENSE`. Chinese glyphs continue through the reader's existing CSS fallback
stack.
