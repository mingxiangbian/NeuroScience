# Mock Test Strategy

## Purpose

Mock tests are for readiness evidence, not just practice volume.

## Trigger Conditions

Open a mock unit only when one of these conditions applies:

- enough section-level evidence exists to test integrated exam execution
- a previous mock needs a comparable second sample
- an external exam deadline requires a readiness decision
- a suspected timing regression cannot be resolved from targeted evidence

## Review Method

For every mock:
- record raw marks or estimated band
- identify timing failures
- identify repeated errors
- append a score event with comparable-condition notes
- update the active or suggested unit only when the evidence is strong enough

## Caution

Do not use one good mock to erase recurring errors. Check whether the same error stays fixed in later timed work.
