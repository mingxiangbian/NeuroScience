# IELTS Academic 写作快速提分与高频表达库

## 这份资料解决什么问题

这不是押题表，也不是让人背诵的范文库。剑桥雅思题目只用于观察长期题型和主题分布，真正目标是建立一套可以迁移到陌生题目的写作系统。

官方评分标准显示，Band 7 的关键不是堆砌生词，而是：

- Task 1 有清楚的 Overview，数据被合理分类，主要趋势或差异得到识别。
- Task 2 清楚回答题目各部分，立场明确，主要观点得到展开和支持。
- 信息有逻辑推进，搭配和句式有一定灵活性，同时经常出现无错误句。

因此，本资料只保留三类内容：

1. 能稳定表达逻辑关系的句架。
2. 高频主题中可跨题复用的准确搭配。
3. 能直接防止当前高影响错误的执行规则。

## 你的最高优先级修复

| 当前风险 | 考场规则 |

# Task 2

## 五分钟承诺法

### 第 1 分钟：锁定题目任务

在草稿上写：

> Proposition: ________
>
> Required answers: ________

如果题目有两个问号，必须写出两个独立答案。

### 第 2 分钟：锁定立场

只写一句：

> I agree / disagree / consider this positive because A and B.

检查 A、B 是否都支持这句话。若理由实际支持反面，立刻修正立场；正文开始后不再重新选择。

### 第 3-4 分钟：建立两个论证链

每段只写五个词组：

> Claim -> Mechanism -> Actor -> Immediate result -> Link

例子不需要是真实新闻。它只需要具体、合理，并能证明段落观点。

### 第 5 分钟：做可写性检查

每个观点必须同时满足：

- 直接回答题目。
- 与另一段不重复。
- 能用简单英语解释原因。
- 能形成一个具体场景。

满足四项后立即开始写，不再寻找“更完美”的观点。

## 主体段最稳定结构

1. **Claim**：本段主张。
2. **Mechanism**：为什么会产生这种结果。
3. **Concrete scenario**：谁在什么情况下做了什么。
4. **Immediate result**：可观察的直接结果。
5. **Link**：该结果如何证明本段主张。

示例骨架：

> One reason is that practical activities provide immediate feedback. This matters because children are more likely to remain engaged when they can see the result of their effort. For example, a pupil who directs a short classroom play can observe how planning and cooperation improve the final performance. This sense of achievement can strengthen the child's motivation to participate in future lessons.

这类课堂情境属于有效例证。它不是统计证据，但它把抽象因果关系变成了可观察的过程。

## 20 个高复用逻辑句架

### 立场与限定：5 个

1. `I largely agree that ..., mainly because ...`
2. `I disagree with the claim that ..., because ...`
3. `Although ... can ..., this does not mean that ...`
4. `The issue is not whether ..., but whether ...`
5. `The extent to which ... is beneficial depends largely on ...`

### 因果与展开：6 个

6. `This is mainly because ...`
7. `This can lead to + noun / noun phrase.`
8. `This, in turn, makes it more likely that ...`
9. `By doing so, people / schools / governments can ...`
10. `Without ..., people may struggle to ...`
11. `Over time, this can result in ...`

### 例证与支持：3 个

12. `Consider, for example, a student / employee / family who ...`
13. `A typical case would be ...`
14. `This can be seen when ...`

### 让步与比较：3 个

15. `Admittedly, ...; however, ...`
16. `This benefit is limited in cases where ...`
17. `A more convincing argument is that ...`

### 方案与结论：3 个

18. `Governments could address this by + -ing ...`
19. `Schools / employers should ensure that ...`
20. `The priority should be to ..., rather than to ...`

使用限制：不要在同一段连续堆叠这些句架。每段选 2-3 个即可，其余句子使用普通主谓结构。

## 36 个高频主题搭配

### 社会、心理与公共政策：8 个

## 六个通用例证入口

遇到陌生题目时，从下面六个角色中选一个，不要等待真实名人案例：

| 角色 | 可用场景 |
| --- | --- |
| 小学生 / 大学生 | 课程、反馈、游戏、实习、学习动机 |
| 员工 / 毕业生 | 培训、生产率、就业、工作生活平衡 |
| 家庭 / 低收入家庭 | 消费、住房、教育和公共服务成本 |
| 通勤者 / 城市居民 | 交通、污染、城市规划、生活质量 |
| 病人 / 医疗系统 | 预防、费用、可及性、心理健康 |
| 小企业 / 消费者 | 广告、创新、自动化、就业和价格 |

一条可用例证只需完成：

> actor -> action or constraint -> immediate result -> connection to the claim

## 五类题型的答题底线

| 题型 | 必须完成 | 常见失分 |
| --- | --- | --- |
| Agree / Disagree | 全文保持同一立场，两个主体段都证明该立场 | 第一段理由与总立场方向相反 |
| Two-part Question | 两个问题各有一个清楚答案和展开 | 第二问只在结论中提一句 |
| Discuss Both Views | 两方各自解释，再明确自己的判断 | 只列观点，不解释为什么有人这样认为 |
| Advantages / Disadvantages | 比较影响的范围、强度或持续时间 | 只列利弊，没有回答是否 outweigh |
| Positive / Negative | 给出总体判断，并说明评价标准 | 同时写正负面却不作最终权衡 |

# Task 1

## 20 分钟分配

| 时间 | 动作 |
| --- | --- |
| 0-3 分钟 | 看标题、单位、年份和对象；圈出 2-3 个主要特征；确定分组 |
| 3-5 分钟 | 写 Introduction 和 Overview |
| 5-16 分钟 | 写两个细节段，只选择支持主要特征的数据 |
| 16-20 分钟 | 核对对象、年份、数字、单位、方向、最高最低、主谓一致 |

## Overview 的选择规则

数据图先问四个问题：

1. 总体上升、下降、稳定还是有不同方向？
2. 谁一直最高或最低？
3. 是否发生交叉、超越或排名变化？
4. 哪个变化幅度最大或最反常？

Overview 通常写 2-3 个最重要特征，不写所有数据，也不受“必须两句话”的限制。

地图 Overview 写整体用途和布局变化；流程图 Overview 写起点、终点、阶段数以及是否循环。

## 22 个稳定表达

### 数据、趋势与比较：14 个

1. `Overall, ...`
2. `The most striking feature is that ...`
3. `X increased, whereas Y declined.`
4. `X remained the largest category throughout the period.`
5. `the number of + plural countable noun`
6. `the proportion / percentage of + noun`
7. `stood at + figure`
8. `accounted for + percentage / share`
9. `rose from A to B`
10. `fell by A / fell to B`
11. `reached a peak of + figure`
12. `remained broadly stable`
13. `overtook / surpassed X in + year`
14. `A and B respectively`

### 地图：4 个

15. `was replaced by ...`
16. `was converted into ...`
17. `was relocated to ...`
18. `remained unchanged`

### 流程：4 个

19. `The process begins with ...`
20. `X is then transported / heated / separated ...`
21. `..., after which ...`
22. `The process culminates in ...`

## 针对现有错误的安全改写

| 不稳定表达 | 稳定表达 |
| --- | --- |
| `the jobs account in healthcare rank first` | `Employment in healthcare was the highest.` |
| `full-time undergraduates ranked first` | `Full-time undergraduates accounted for the largest proportion of users.` |
| `almost 100 times than the 1800 figure` | `almost 100 times the 1800 figure` |
| `the share declined by 57%`（76% 到 19%） | `the share fell by 57 percentage points` |
| `fluctuated`（只有一次先升后降） | `rose to a peak of ..., before falling to ...` |
| `leads to the result that + clause` | `means that + clause` 或 `leads to + noun phrase` |

## Task 1 禁止事项

- 不为了避免重复而替换 `number`、`proportion`、`population`、`employment`。
- 不使用自己不确定搭配的“高级词”。
- 不把每个数据都写进正文。
- 不在 Overview 中加入原因、评价或个人观点。
- 不把 `percentage` 和 `percentage points` 混用。
- 不用 `rank first` 描述人数或数量，优先用 `was the highest`。

# 考前两天的使用方法

## 8 月 27 日

1. 从 20 个 Task 2 句架中选 12 个，只做替换练习，不背完整段落。
2. 从教育、社会、工作和科技中各选 3 个主题搭配，共 12 个。
3. 对两道陌生 Task 2 只做五分钟提纲，每段必须有例证链。
4. 对三张 Task 1 图只写 Overview，并口头说明为什么舍弃其他细节。

## 8 月 28 日

1. 完成一次 60 分钟完整写作，Task 2 40 分钟，Task 1 20 分钟。
2. 不逐句润色全文，只统计：漏答、立场反向、无例证、搭配错误、数字错误和检查遗漏。
3. 只重写最差的一个 Task 2 主体段和 Task 1 Overview。
4. 睡前复习 34 个主动表达，不再增加词表。

## 考场

- Task 2 开始前执行五分钟承诺法。
- 每个主体段只承担一个主张。
- 例子使用普通人物和具体场景，不等待名人、新闻或统计数字。
- Task 1 允许准确重复核心统计名词。
- 最后检查优先级：漏答和立场 -> 主语谓语 -> 数据与单位 -> 单复数和拼写 -> 可删的多余词。
